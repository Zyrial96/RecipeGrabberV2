# RecipeGrabberV2 2.1.0

Signed Android release, version code 2. Requires Android 12/API 31 or newer.

## Changes

- Refreshed light/dark design, image-backed recipe library, favorite filtering,
  cooking checklists and setup/settings/extraction screens.
- Bounded UI transitions and refreshed app artwork/colors.
- Originalvideo ansehen in recipe details opens the saved HTTPS source in the
  installed video app or browser. Missing or unsafe sources do not show a link.

## Downloads And Installation

Install `app-release.apk` from this GitHub release. The signed
`app-release.aab` is provided separately for distribution tooling, not direct
installation. Verify downloads against `SHA256SUMS`.

The signing identity is unchanged from the earlier local signed release.
Debug installations use another certificate and cannot be updated in place:
first create and verify a current recipe backup before any authorized removal.
After reinstalling, reconnect Drive and restore the snapshot. Recipe snapshots
do not contain API keys, settings or OAuth tokens. Do not clear an installation
without verifying its backup.

## Verification

154 JVM tests, Android lint, signed APK/AAB verification and ten release-tooling
tests passed. The exact production APK was installed on a Xiaomi Mi 11:
four-recipe Drive recovery, duplicate-free repeat, restart persistence, recipe
details, portion scaling, light/dark rendering and the original-video handoff
passed. A fresh four-recipe backup was also created by the release app.

See the [device acceptance audit](https://github.com/Zyrial96/RecipeGrabberV2/blob/main/.planning/audits/2026-10-23-mi11-release-2.1.0.md)
for artifact identities and limits. This is an early-stage project; it is not
Play-store publication or a guarantee for every video, provider or device.
